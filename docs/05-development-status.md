# 开发状态与验证记录

更新日期：2026-09-20

## 当前实现

实现已建立文档定义的分层 C++20 工程，完成 M1—M3 与 M4 的本地/Mock 代码基线，并进入 M5 Windows 闭环阶段。产品入口已按用户反馈改为“空白世界 → 导入小说 → 章节切片 → 待校对候选”；旧资料安装器和测试夹具不再编入正式程序，但有限领域推演逻辑尚待通用化：

- `domain`：领域状态、人物知识、唯一物品、秘密传播与规则不变量。
- `engine`：无需 API Key 的三回合 `MockProvider`、逐角色可见上下文和生产会话调度。
- `storage_sqlite`：SQLite C API RAII、迁移、WAL、短事务、命令去重、提交链、重启恢复和分支隔离。
- `application`：打开、单步/连续推演、暂停/恢复/取消、导演介入、创建/切换分支用例。
- `viewmodels` / `ui/qml`：后台执行数据库和 Mock 调用，GUI 线程只更新界面状态。
- `contracts`：命令、受限人物意图、人物卡和虚构时间的 draft-2020-12 Schema 基线及合法/非法夹具。
- `world_entity`：通用世界条目的稳定 ID、修订历史、软删除、别名、标签、扩展属性和乐观并发。
- `source_document`：TXT/Markdown UTF-8 标准化、原文与标准化资产、章节索引及 Unicode 码点证据区间。
- `evidence_reference`：字段级证据绑定稳定条目、来源、码点区间、引文哈希与来源性质；可从记录跳回原文选择区。
- `character_blueprint`：核心身份、可适配能力、装备、经历和作者私密说明独立字段；历史版本不可变。
- `package`：依赖无关 JSON 与受限 ZIP 实现；世界包、人物包支持摘要校验及单事务导入。
- `provider_connection`：提供商元数据修订、Windows Credential Manager 凭据边界、后台端点验证与固定脱敏错误。
- `providers`：OpenAI Responses、OpenAI-compatible Chat Completions、Anthropic Messages、Gemini GenerateContent 的独立请求/响应转换、usage 与终止原因分型；凭据不进入请求 DTO/日志。
- 原生界面：左侧项目／工作区列表与二级功能入口，右侧工作区；浅色／深色主题集中配色并持久化。
- 开发预览：根目录一键编译脚本自动配置本机 Qt 工具链、增量编译并打开桌面版，可选运行测试。
- 小说提取：离线模式为默认；可将任务绑定到允许远程发送的模型连接，手动执行单块抽样，模型引文必须经本地原文校验后进入待校对区。合成文本测试覆盖零隐式请求与单步预算边界，真实小说远程抽取质量仍未验收。

## M2 验收结论

M2 的本地与 Mock 退出基线已通过：AC-05（中文/emoji/CRLF 码点定位）、AC-06（故事时间过滤，`in_text_claim` 保留为 claim 而非世界真相，未知不强填）、AC-07（检查点、unknown 与缓存恢复）、AC-08（提示词要求未知字段保持缺失，推断保留 hypothesis 标记）、AC-18（来源中的“发送 API Key”仅作为不可信文本，提取层没有凭据/工具权限）。

## M4 验收结论

本地与 Mock 基线覆盖 AC-14、15、19、20、21、22、23，并复用 M3 的分支根与历史模式覆盖 AC-24 的数据边界。特别地，暂停期间返回的模型结果只结算 usage 并保存为 `needs_review`，不会推进分支；显式恢复后会重新校验原输入提交且不产生第二次模型调用。

AC-13 要求至少两家真实模型参与同一场景。当前只有一个 DeepSeek 连接完成独立结构化生成自检，尚未把真实网关接入可恢复推演会话，也没有第二家厂商凭据，因此仍不能宣称真实厂商退出条件已经通过。当前推演状态结构仍是有限测试领域；扩展到任意世界规则属于后续领域适配工作，不能把协议转换测试误称为通用剧情质量验证。

## M5 当前验收结论

分支比较、结果采纳、导出、脱敏诊断、10,000 条实体压力基线与便携发行烟测已有本地实现。2026-09-20 Windows UI 预设通过 3/3 测试；外部本地小说识别 688 个含书前部分的章节区间、生成 870 个不跨章节的步骤，并在前 10 步形成 41 条可溯源、待人工校对的候选。浅色／深色界面均已启动截图；真实抽取质量与整本执行耗时尚未验收。

M5 尚未达到路线文档的完整退出条件：没有外部干净 Windows 安装机、代码签名证书、两家真实模型凭据与真实用户验收，NSIS 安装器也尚未在本机生成。因此当前仍标记为进行中，不能将便携目录烟测等同于 AC-37 完整通过，也不能宣称 Windows 0.3-beta 已发布。
