## 已确定的方向

- 导入小说，提取并编辑世界观、地图、人物、势力、事件、时间线、物品与关系。
- 支持手动创建世界、导入他人世界模板，以及可复用人物卡。
- 将人物放入指定世界、时间和事件，推演互动与剧情变化。
- 多家模型 API 可配置；不同人物可以使用不同模型。
- 优先开发 Windows，架构覆盖 macOS、Linux、Web 和 Android。
- 根据用户提出的C++方向，开发计划采用C++核心，不再要求Rust工具链；Qt及具体配套组件属于本版工程建议。

## 暂定方案

- 本地优先，自填 API Key；云端与同步作为后续能力。
- 保留原著基线，通过独立分支推演新剧情。
- 桌面与Android采用Qt 6 + QML/Qt Quick，核心C++20，构建CMake，数据SQLite。
- 正式Web版采用浏览器界面与C++服务端；浏览器前端建议TypeScript，框架到Web阶段确定。Qt WebAssembly仅作为可选复用实验。
- 首版完成“导入—校对—人物入场—多模型推演—分支比较—导出”的完整闭环。

暂定方案可以根据用户后续偏好调整；不将未回复视为已确认。

“叙演”对应叙事与推演，“工坊”强调作者控制与反复试验；`XuyanForge` 用作英文名及目录名。2026-09-18 对中文名、英文名及英文名与软件/GitHub组合进行了公开网页检索，未发现明确的同名知名软件项目。此结果仅用于当前内部命名，不代表名称全球唯一；未核验商标、域名或包名注册状态。
